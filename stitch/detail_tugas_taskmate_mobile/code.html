Deskripsi Tugas

Buatlah program dalam bahasa Python atau Java yang mengimplementasikan struktur data Graf. Program harus mampu melakukan operasi dasar seperti:

  • Menambahkan Node (Vertex)
  • Menambahkan Edge (dengan atau tanpa bobot)
  • Mencari jalur terpendek menggunakan algoritma Dijkstra atau A*

Pastikan kode dikomentari dengan baik dan disertai dengan dokumen penjelasan (format PDF) maksimal 3 halaman.
